# SVM Drug Classification Exercise

This repository contains a simple Support Vector Machine (SVM) classification example using the `drug200.csv` dataset.

## Files
- `exercise-summary-functions-and-maps-svm.py` — Python script version
- `exercise-summary-functions-and-maps-svm.ipynb` — notebook version

## Setup
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

## Run
```bash
python exercise-summary-functions-and-maps-svm.py
```
